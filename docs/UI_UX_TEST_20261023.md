## Fixed during this pass

- Saved profile data was being updated while typing, before Save. Profile name and account name now have separate drafts.
- A profile subscription guard ran for demo rather than authenticated users and could crash an unconfigured demo. Corrected the guard.
- Mobile summary table required sideways scrolling without making that clear. All four columns now fit on small screens.
- Expense notifications selected the wrong finance section. Routing now chooses expense, summary, or collection by notification type.
- Demo logout and trip settings actions did nothing; demo exit is now a link, unavailable features explain the requirement.
- Demo QR upload silently did nothing. Disabled it with an explanation.
- Browser native English form validation overrode existing Thai errors. Login now uses the application's validation consistently.
- Invalid guest/vote links exposed raw database messages. Replaced those with Thai guidance; guest errors include a home link.
